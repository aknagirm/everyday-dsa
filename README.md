# DSA Practice

This repository contains my Data Structures and Algorithms practice solutions, notes, and revision material.

## Goal

The goal of this repo is to:
- improve problem-solving speed
- recognize common interview patterns
- write clean and readable solutions
- revise important problems efficiently
- prepare for technical interviews

## Approach

I focus on:
- pattern-based practice
- medium-level interview problems
- writing clear complexity analysis
- revisiting old problems regularly

I am not aiming for competitive programming style practice.  
The focus here is interview readiness and consistency.

## Topics

- Arrays

- Hash Maps
- Two Pointers
- Sliding Window
- Stack and Queue
- Linked List
- Recursion and Backtracking
- Trees
- Binary Search
- Heaps
- Graphs
- Dynamic Programming
